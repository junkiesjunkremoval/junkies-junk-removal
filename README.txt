HOW TO UPDATE THE GITHUB WEBSITE
1. Open https://github.com/junkiesjunkremoval/junkies-junk-removal
2. Open each file in the repository (index.html, styles.css; add script.js if needed).
3. Use the pencil/Edit icon to edit a file, or choose Add file > Upload files to upload files.
4. To upload all files: extract this ZIP first, then upload index.html, styles.css, script.js, CNAME, and README.txt into the repository's root (the top level). Do not upload the ZIP itself. If GitHub asks whether to replace existing files, review and confirm.
5. Commit the changes to the main branch.
6. Wait a few minutes and refresh the site.
