BEFORE PUBLISHING:
1. Open index.html and replace YOUR-EMAIL@example.com with your real business email.
2. Replace the https://m.me/ placeholder with your actual messaging link, or remove that button.
3. Confirm services, service area, and business details are accurate.
4. This is a static website; the quote buttons open email/message links and do not store form submissions.

FREE HOSTING:
You can publish this with GitHub Pages. The custom domain at the root (yourdomain.com) can use GitHub Pages DNS records, but use the exact current records GitHub provides in its Pages settings. Keep your Wix domain registration; update DNS records in Wix only after GitHub Pages is configured and has provided the required records. Do not change nameservers, and do not delete email-related MX/TXT records.
